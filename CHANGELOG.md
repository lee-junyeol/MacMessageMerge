# Changelog

## 1.0.0 - 2026-08-09

- CSV import with UTF-8, CP949 and EUC-KR support
- `{name}` and `{phone}` mail-merge variables
- New Messages conversation for every recipient using Command-N
- Direct Accessibility text insertion instead of clipboard paste
- AppleScript compile/permission diagnostics
- Local-only Waitress server on `127.0.0.1`
- Removed persistent contact storage and unnecessary CORS dependency
- Removed Bootstrap/CDN dependencies; UI is fully local
